# Electronic Parachute Reefing PCB (Reef V3)

KiCad 10 project for the electronic parachute reefing controller.

- `V2_solenoid_removed/` is the V2 board (solenoid circuit removed, all parts on the top side). The original pre-V2 design is not tracked here.
- `libs/UL_Parts.pretty/` is a snapshot of the custom footprint library. The project's `fp-lib-table` still points at `C:/Users/austi/Documents/KiCad/10.0/footprints/UL_Parts.pretty`; footprints are also embedded in the `.kicad_pcb`, so the board opens without the library.
